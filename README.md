# RG Rotate 3D Test Game

Anbernic **RG Rotate**（3.5インチ 720×720 正方形液晶・十字キー＆物理ボタン搭載・スティック非搭載）に最適化したGodot 4製 3Dテスト用ゲームです。

---

## 🎮 操作方法 (Controls)

本アプリは「**スティックが無くても快適に遊べる三人称視点（TPS）タンク/カメラ連動コントロール**」を採用しています。

| ボタン / キー | 動作 | 説明 |
|---|---|---|
| **上キー (↑ / W / D-Pad上)** | **前進 (Forward)** | キャラクターが向いている正面へ前進します。スムーズな加速・足踏みアニメーション付き。 |
| **下キー (↓ / S / D-Pad下)** | **後退 (Backward)** | ゆっくりと後ろ向きに歩きます（前進の約50%速度）。 |
| **左キー (← / A / D-Pad左)** | **左旋回 (Turn Left)** | 左を向きます。旋回時に自然なバンク（体の傾き）が発生します。 |
| **右キー (→ / D / D-Pad右)** | **右旋回 (Turn Right)** | 右を向きます。 |
| **Space / Aボタン** | **ジャンプ (Jump)** | 障害物や段差を跳び越えます。着地音・ジャンプ音付き。 |
| **Shift / Bボタン / Xボタン** | **ダッシュ (Sprint)** | より速く走ります。 |
| **Qキー / RBボタン** | **180°クイックターン (Quick Turn)** | スティックのない端末で真後ろを振り向くための快適補助機能。瞬時に180度反転します。 |
| **Rキー / Selectボタン** | **リセット / リスポーン (Reset)** | 初期位置に戻ります（ステージ外へ落下した場合も自動で初期位置にリスポーンします）。 |

## 📱 RG Rotate 向け設計ポイント

1. **720 × 720 正方形解像度**
   - 画面比率 1:1 に最適化されたHUDおよびカメラFOV設計。
   - スイベル構造（画面回転）時にも綺麗に収まるレスポンシブなUIレイアウト。
2. **物理十字キー（D-Pad）専用チューニング**
   - 上下キーで直感的な前進・後退。
   - 左右キーで適切な旋回速度（滑らかな回転補間）を適用。
   - 画面背後からプレイヤーを滑らかに追従する三人称カメラ（SpringArm3D + ダンピング補間）により、右スティックでの視点操作を一切必要としません。
3. **3D物理・プラットフォームの動作テスト要素**
   - **スロープ（坂道）**: 傾斜地の移動テスト
   - **階段**: 段差昇降テスト
   - **飛び石足場**: ジャンプ距離・高低差テスト
   - **動くリフト (Moving Platform)**: プレイヤー追従移動テスト
   - **押せる物理ブロック (RigidBody3D)**: 物理衝突テスト
   - **収集クリスタル (8個)**: 取得判定・パーティクル・クリア演出
4. **自己完結型プロシージャルサウンド**
   - 外部音声ファイルへの依存なしに、GDScript内部の `AudioStreamWAV` 合成により、ジャンプ音・コイン取得音・着地音・リスポーン音を生成・再生します。

## 🚀 起動方法

### Windows PCでのテスト実行
プロジェクトルートで以下のコマンドを実行、またはGodotエディタで本フォルダを開いて実行できます：

```powershell
& "C:\Users\user\Downloads\Godot\Godot_v4.7.2-stable_win64_console.exe" --path .
```

### Android (RG Rotate 実機) へのエクスポート
1. Godotエディタの「プロジェクト」→「エクスポート」を開く
2. Androidプリセットを追加
3. パッケージ（APK）をビルドしてRG Rotateに転送・インストール
